# Study Widgets

Два виджета для Windows 10/11 в одном репозитории.

**Расписание** показывает неделю из Google Календаря, задачи Google Tasks и дедлайны LMS ШАД. Можно отмечать и возвращать задачи, листать недели и открывать задания. Календарь проверяется раз в две минуты; Tasks и ШАД — раз в час. Галочки и кнопка обновления синхронизируются сразу. При недоступной сети остаётся последняя сохранённая копия.

**Учебный таймер** считает время по категориям за выбранный день. Поддерживает паузу, историю, графики за день/неделю/месяц, выходные, отметки пробуждения и сна, дневной сон и объединение дней после ночи без сна. ПКМ по категории открывает «Очистить»; очистку можно отменить, пока меню открыто. Закрытие крестиком скрывает окно, а запущенный таймер продолжает работать.

## Установка

Нужны 64-битная Windows, Python 3.12+ с Tk и Git. Для синхронизации Tasks/ШАД нужен установленный Microsoft Edge.

```powershell
git clone https://github.com/evgrart/study-widgets.git
cd study-widgets
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

Если `python` недоступен, передай путь к интерпретатору:

```powershell
.\install.ps1 -Python 'C:\path\to\python.exe'
```

Установщик создаёт `.venv`, устанавливает зависимости и добавляет ярлыки **Study Widgets - Schedule** и **Study Widgets - Timer** на рабочий стол и в меню «Пуск». Если доступен GCC или MSVC, он также собирает мост прокрутки; без компилятора работает Python-обработчик.

Вручную приложения запускаются так:

```powershell
.\.venv\Scripts\pythonw.exe .\schedule\widget.py
.\.venv\Scripts\pythonw.exe .\study\widget.py
```

## Подключение расписания и задач

```powershell
.\.venv\Scripts\python.exe .\configure.py
```

Введи свою секретную iCal-ссылку из Google Календаря: **Настройки → нужный календарь → Интеграция календаря → Секретный адрес в формате iCal**. Затем укажи почту аккаунта для Google Tasks. Ввод ссылки скрыт; пароль программа не запрашивает.

Открой расписание. Меню по правой кнопке на шапке позволяет изменить настройки. Кнопка **Дедлайны / Задания** переключает боковую панель. В Tasks нажми **Подключить Google Tasks**, войди в указанный аккаунт в отдельном окне Edge и дождись закрытия окна. Для дедлайнов аналогично войди в ШАД. Фоновая синхронизация работает без видимых окон браузера. Она читает задания и меняет только те галочки задач, которые ты нажал в виджете.

Синхронизация использует веб-интерфейсы, поэтому после изменений сайтов может потребоваться обновление кода. При сбое сохранённые данные не удаляются. Обновление Google iCal может запаздывать относительно самого календаря.

Чтобы получать задачи и дедлайны раз в час даже при полностью закрытом расписании:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\schedule\install_tasks_sync.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\schedule\install_shad_sync.ps1
```

## Горячие клавиши

Необязательно: установи AutoHotkey v2 и передай путь к его исполняемому файлу:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install_hotkeys.ps1 -AutoHotkey 'C:\Program Files\AutoHotkey\v2\AutoHotkey64.exe'
```

**Win+1** показывает/скрывает расписание, **Win+2** — таймер. Помощники запускаются при входе в Windows; сами окна открываются по запросу. Эти сочетания заменяют стандартное переключение закреплённых приложений Windows.

## Данные

Личные настройки, базы и отдельные профили входа хранятся вне репозитория:

- `%LOCALAPPDATA%\StudyWidgets\Schedule` — календарь, задачи и ШАД;
- `%LOCALAPPDATA%\StudyWidgets\Study` — категории, время и сон.

Категории изначально пустые: добавь свои кнопкой **+ Категория**. Таймер записывает время за выбранную дату, даже если открыт прошлый день. «Не спал» объединяет выбранный день со следующим; дневной сон отдельно вычитается из бодрствования. Статистика сна — расчёт по твоим отметкам, включая заданное время засыпания, а не измерение сна.

Секретную iCal-ссылку, профили браузера и базы нельзя публиковать. Для отдельной тестовой установки можно задать `SCHEDULE_WIDGET_DATA_DIR` и `STUDY_WIDGET_DATA_DIR`; горячие клавиши и запланированные задачи рассчитаны на стандартные папки.

## Проверка и удаление автозапуска

```powershell
.\.venv\Scripts\python.exe .\scripts\run_tests.py
.\.venv\Scripts\python.exe .\scripts\check_privacy.py --history
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\remove_background.ps1
```

Последняя команда удаляет фоновые задания и автозапуск помощников. Чтобы удалить приложения, заверши их через меню по ПКМ на шапке, удали ярлыки и папку клона. Папки с личными данными сохраняются отдельно.
